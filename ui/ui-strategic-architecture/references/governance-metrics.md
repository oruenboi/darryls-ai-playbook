# Governance Metrics

Use these metrics to monitor long-term UI system health.

## Consistency
- Token adoption rate across active products.
- Component reuse ratio versus one-off implementations.
- Theming parity across brands and modes.

## Delivery
- Lead time for design-system-backed features.
- Defect rate in UI regressions by release.
- Migration completion for deprecated components.

## Risk and Debt
- Open debt items by severity and age.
- Number of undocumented component overrides.
- Drift findings from periodic architecture audits.
